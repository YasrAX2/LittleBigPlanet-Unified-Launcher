# Image sources

The default Sackboy background, three LittleBigPlanet game covers and ten Popit color icons were supplied or selected by yasrax2 for the launcher. These are the same pictures used in the creator's local appearance. No AI-generated images are included.

The 14 approved PNG files are embedded from `src-tauri/assets/default-art/`. `manifest.json` records their SHA-256 hashes. The original game artwork belongs to its respective rights holders, including Sony Interactive Entertainment and the game creators. These images are not covered by the source code's MIT license; no open-content license or redistribution permission is claimed.

The launcher icon is original. Lucide icons and Rubik fonts retain their bundled license notices. Blur is a local CSS effect. Users may import their own PNG/JPEG covers and backgrounds; these custom pictures stay in local application data and are never uploaded by the launcher.

Private version-history screenshots and local configuration are excluded from source and release packages. See [artwork and distribution](LEGAL.md), [privacy](../PRIVACY.md) and [third-party notices](../THIRD-PARTY-NOTICES.md).
