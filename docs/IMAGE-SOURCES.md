# Image sources and rights

Current public packages include no game artwork, screenshots, Sackboy silhouettes or supplied backgrounds. They contain the original launcher icon, Lucide interface icons and licensed Rubik font. Their notices accompany the application.

Users can select local PNG/JPEG backgrounds and game covers. Pictures are copied only to local application data and are not uploaded. Blur is a CSS effect; no AI image service is used. Selecting or crediting an image does not establish redistribution rights.

Earlier versions used externally sourced game covers, screenshots and a supplied Sackboy picture. Releases/tags v1.0.0, v1.1.0 and v1.2.0 were removed on 17 November 2026. Public main and retained v1.2.1 start from an artwork-free snapshot. Private comparison pictures are outside Git. Downloaded copies and GitHub caches may remain.

See [artwork and distribution](LEGAL.md), [privacy](../PRIVACY.md) and [third-party notices](../THIRD-PARTY-NOTICES.md). Game imagery and trademarks are not covered by the MIT source license.
