# Artwork, names and distribution

Patchwork Pod is an unofficial launcher created by yasrax2. It is not affiliated with or endorsed by Sony, Media Molecule or Sumo Digital. Game names identify compatible software; the code's MIT license does not grant rights in those names, games or artwork.

Finding an image through Google does not establish permission to redistribute it. Google instructs users to verify the actual license: https://support.google.com/websearch/answer/29508 . Sony identifies game artwork and associated imagery as protected by the respective owners: https://www.playstation.com/en-us/legal/copyright-and-trademark-notice/ .

Public builds include the default Sackboy background, game covers and Popit icons selected by yasrax2. Their inclusion does not grant an artwork license: the code's MIT license excludes third-party game imagery and trademarks. The launcher contains no game files, music, firmware or keys. Custom imported pictures remain local. Credit or a source link is not a substitute for redistribution permission.

GitHub downloads retain stable v1.3.0 and prerelease v1.5.0 with these appearance defaults. Private comparison pictures stay outside the repository. Removed releases cannot recall previously downloaded or cached copies.
